# Font licenses

The embedded WOFF subsets are used to keep each SVG self-contained for GitHub profile rendering. Instrument Serif and Geist are distributed under the SIL Open Font License 1.1. Geist Mono is represented by the Geist regular subset because the reference's compact monospaced labels use the same visual family; all three font family sources are available from Google Fonts.

- Instrument Serif: https://fonts.google.com/specimen/Instrument+Serif
- Geist: https://fonts.google.com/specimen/Geist
- SIL Open Font License: see the adjacent OFL license files.
